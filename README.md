📊 Meta Ad Performance Analysis Project Overview

This project presents an interactive Power BI Dashboard that analyzes advertising performance across Meta platforms (Facebook and Instagram). The dashboard provides meaningful insights into campaign performance by tracking key marketing metrics, user engagement, audience demographics, and regional performance.

Users can switch between Facebook and Instagram dashboards to compare advertising results and explore trends using interactive filters and dynamic visualizations.

🎯 Objective The objective of this project is to help marketers and business stakeholders:

Monitor advertising performance. Compare Facebook and Instagram campaigns. Analyze audience engagement. Track campaign KPIs.
